About Weather Info App

Overview

Weather Info App is a comprehensive web application built with Flask that provides real-time weather information for cities worldwide. Get instant access to current weather conditions, temperature, humidity, wind speed, and much more.

Features

  • 🌡️ Real-time Weather Data: Current temperature with feels-like information
  • 💨 Wind Information: Wind speed and direction details
  • 💧 Humidity & Pressure: Atmospheric pressure and humidity levels
  • 🌅 Sunrise & Sunset: Accurate sunrise and sunset times
  • 👁️ Visibility: Current visibility conditions
  • 🔄 Unit Conversion: Toggle between Celsius and Fahrenheit
  • 📱 Responsive Design: Works seamlessly on all devices
  • ⚡ Fast & Cached: Optimized performance with data caching
  • 🔌 API Endpoint: JSON API for developers

Technology Stack

Backend:
  • Python 3
  • Flask Web Framework
  • Flask-Caching
  • Requests Library
Frontend:
  • HTML5 & CSS3
  • Bootstrap 5
  • JavaScript (ES6+)
  • Responsive Design

API Integration

This application uses the OpenWeatherMap API to fetch real-time weather data. The API provides comprehensive weather information including:

  • Current weather conditions
  • Temperature and feels-like temperature
  • Atmospheric pressure and humidity
  • Wind speed and direction
  • Cloudiness and visibility
  • Sunrise and sunset times

API Endpoints

GET /api/weather/<city>

Get weather data in JSON format for a specific city.

Example:

GET /api/weather/London

Response:

{
  "success": true,
  "data": {
    "city": "London",
    "country": "GB",
    "temp_celsius": 15.5,
    "temp_fahrenheit": 59.9,
    "humidity": 72,
    "description": "Partly cloudy",
    ...
  }
}

Performance & Caching

To optimize performance and reduce API calls, weather data is cached for 10 minutes per city. This ensures fast response times while staying within API rate limits.

Error Handling

The application includes comprehensive error handling for:

  • Invalid city names
  • API connection errors
  • Rate limit exceeded
  • Network timeouts
  • Missing API configuration

Privacy & Security

This application does not collect, store, or share any personal information. All weather data is fetched directly from the OpenWeatherMap API and cached temporarily for performance optimization.
